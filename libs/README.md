# libs — consumable Clojure libraries built with gleam-clj

Each directory here is a self-contained Clojure library you can pull as a
git dependency. The `src/` in each is a **build artifact** — committed
Clojure, regenerated by that lib's `build.sh` — so consuming a lib needs
**no Rust or Gleam toolchain**, just the JVM.

## Which one do I want?

| Library | You want it when… | Public API |
|---|---|---|
| **[gleam-parser](gleam-parser/)** | you need to **parse Gleam source** from Clojure (it's [glance](https://hexdocs.pm/glance/), Gleam's own parser, compiled here) | `gleam-parser/parse`, `parse!`, `defs` |
| **[mb-lib-parse](mb-lib-parse/)** | you want Metabase's native-query `{{param}}` / `[[optional]]` parser, or a worked example of porting a real Clojure module to Gleam | `metabase.lib.parse-gleam/parse` |
| **[gleam-runtime](gleam-runtime/)** | you **compiled your own** Gleam modules and vendored the `.clj` into your tree — this is just the runtime underneath (prelude + FFI core + stdlib) | *(no API; a classpath dependency)* |

Rule of thumb: `gleam-parser` and `mb-lib-parse` are **finished tools you
call**. `gleam-runtime` is the **substrate** you depend on when you're
generating and shipping your own compiled Gleam.

## How to consume one

Every lib is pulled the same way — a git dep with `:deps/root` pointing at
its directory:

```clojure
;; deps.edn
{:deps {io.github.escherize/gleam-parser
        {:git/url "https://github.com/escherize/gleam-clj"
         :git/sha "5f0f20df19b717e85e86d996d0114e26933091d2"
         :deps/root "libs/gleam-parser"}}}
```

Then:

```clojure
(require 'gleam-parser)
(gleam-parser/defs (gleam-parser/parse (slurp "src/thing.gleam")))
;; => ({:kind :function, :name "main", :publicity "Public", :parameters 0} ...)
```

Swap `gleam-parser` for `mb-lib-parse` (root `libs/mb-lib-parse`) or
`gleam-runtime` (root `libs/gleam-runtime`) as needed. Each lib's own
README has the full API and examples.

## Shared traits

- **Malli schemas** on every public fn (`{:malli/schema …}` metadata),
  derived from the original Gleam types — `malli.instrument` and its
  clj-kondo type-config emission work out of the box, zero runtime cost
  until you opt in.
- **clj-kondo clean** — each lib exports a `.clj-kondo` config (a hook that
  understands the compiled `with-use` macro), so linting works for you too.
- **Verified** — `gleam-parser` parses its own source on the JVM;
  `mb-lib-parse` passes Metabase's own test suite plus 20,000 differential-
  fuzz comparisons against the original.

## Building a lib (contributors only)

`./libs/<name>/build.sh` recompiles that lib's Gleam sources and refreshes
its `src/` artifact. The top-level `check.sh` builds and tests all of them.
See the repo README for the compiler.
